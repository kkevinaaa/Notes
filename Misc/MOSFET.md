# 1 半导体种类
## 1.1 P 型半导体

P 型半导体（P-type semiconductor）是在本征半导体中掺入三价元素形成的，例如硼、铝。这些杂质原子缺少一个价电子，容易在晶体中形成空穴（hole）。

P 型半导体中的多数载流子（carrier）是空穴，少数载流子是电子。电流传导主要表现为空穴移动。掺入的三价杂质称为受主杂质，因为它倾向于接受电子。

## 1.2 N 型半导体

N 型半导体（N-type semiconductor）是在本征半导体中掺入五价元素形成的，例如磷、砷、锑。这些杂质原子比硅多一个价电子，容易提供自由电子。

N 型半导体中的多数载流子是电子（electron），少数载流子是空穴。电流传导主要由电子移动完成。掺入的五价杂质称为施主杂质，因为它倾向于提供电子。

P 型半导体和N 型半导体整体保持电中性。

# 2 二极管

![[Pasted image 20260627215521.png]]

二极管（diode）由 P 型半导体和 N 型半导体接触形成，中间形成 PN 结（PN junction）。当 P 端接高电位、N 端接低电位时，二极管处于正向偏置（forward bias）状态，外加电压会削弱 PN 结内部的阻挡作用，使电子从 N 区进入 P 区，空穴从 P 区进入 N 区，并在结区附近复合，从而形成稳定的正向电流。即：**电流可以从P型半导体流向N型半导体。**

当外加电压方向相反时，二极管处于反向偏置（reverse bias）状态，PN 结附近的耗尽层（depletion region）变宽，载流子难以通过，因此只有极小的反向漏电流（leakage current）。根据这一原理，可以制成具有单向导电性的二极管元件。

电路中通常认为电流允许从二极管的正极（anode）流向负极（cathode）。

# 3 三极管

![[Pasted image 20260627221158.png]]

三极管（transistor）可以看作由三个掺杂区域组成的半导体器件，常见结构包括 NPN 型和 PNP 型。它内部相当于包含两个 PN 结，因此具有比二极管更复杂的控制能力。三极管有三个引脚：基极（base, B）、集电极（collector, C）和发射极（emitter, E）。

## 3.1 电气特征

以 NPN 型三极管为例，当基极和发射极之间加入合适的正向电压时，基极会流过一股较小的电流。这股小电流会改变三极管内部的导通状态，使集电极和发射极之间可以通过较大的电流。若基极电流消失，集电极和发射极之间的主电流也随之截止。根据这一特性，三极管可以用作电子开关，也可以用作信号放大器。

三极管属于**电流控制型器件**。它的核心特点是用较小的基极电流控制较大的集电极电流。作为开关使用时，可以通过控制基极电流来决定主电流是否导通；作为放大器使用时，可以让较小的输入电流变化引起较大的输出电流变化。

> 三极管的缺点也来自这一结构。由于控制过程本身需要基极电流，因此会产生一定功耗；主电流需要经过半导体结区，也会带来压降和损耗。若要通过更大的电流，器件面积和功耗通常也会增加。因此在高密度、低功耗的大规模集成电路中，三极管逐渐被 MOSFET 取代，但它在开关、放大和驱动电路中仍然是非常基础的器件。

## 3.2 原理

![[Pasted image 20260627223201.png]]

这张图讲的是 NPN 三极管在“正向有源区”的工作方式，也就是最经典的放大状态。条件是：

- $V_{BE}>0$，基极 B 相对发射极 E 为正，BE 结正向偏置 forward bias；
- $V_{CB}>0$，集电极 C 相对基极 B 为正，CB 结反向偏置 reverse bias。

发射区写成 $N^+$，意思是重掺杂。它里面有大量电子，作用是“发射”电子。基区是 P 型，而且做得很薄，图上标了 $X_B$，这就是基区宽度。集电区是 N 型，掺杂通常比发射区轻一些，但面积和耐压设计更强，作用是收集从发射区来的电子。

### 3.2.1 未导通时

NPN 里面有两个 PN 结：发射结 BE 和集电结 CB。两个结都没有合适偏置，电子不能自由从 E 跑到 C。三极管此时近似截止。

### 3.2.2 导通时

现在给 BE 结正向偏置，也就是让基极电位比发射极高大约 $0.6\sim0.7V$。这一步会降低发射区和基区之间的势垒。势垒降低后，发射区中的大量电子就能越过 BE 结，注入到 P 型基区中。

> 图右下角能带图里，发射区到基区之间原本有一个能量“坡”，加上 $V_{BE}$ 后，这个坡被压低了 $qV_{BE}$。

这些电子进入基区后，有一小部分会和基区中的空穴复合，这部分复合需要外部基极继续补充空穴，因此形成基极电流 ($I_B$ ，从 B 流向 E )。另一大部分不会复合，因为基区很薄，而且掺杂较轻，扩散到集电结附近。

这时 CB 结虽然是反向偏置，但它并不阻止这些已经进入基区的电子。反向偏置的 CB 结在结区形成很强的电场，这个电场会把到达结区附近的电子迅速“扫”进集电区。于是电子从发射区进入基区，再被集电区收走，形成从 C 到 E 的传统电流 ($I_C$)。

> 这里最关键的一点是：CB 结反向偏置时，对多数载流子的普通正向通过是阻挡的；但对已经注入到基区的少数载流子电子，它会起到收集作用。图下面那句话 “Collector collect the electrons injected from emitter” 说的就是这个过程。

![[Pasted image 20260627225145.jpg|341]]

所以 NPN 三极管的电流门控过程可以概括为：


```text
V_BE 增大
→ BE 结势垒降低
→ 发射区向基区注入更多电子
→ 大部分电子穿过很薄的基区
→ CB 反向电场把电子扫入集电区
→ 集电极电流 I_C 增大
```

基极的控制作用来自两个方面。第一，$V_{BE}$ 控制 BE 结势垒高度；第二，基极需要提供少量复合电流 ($I_B$)。由于大多数电子都被集电极收走，只有少数在基区复合，所以 $I_B$ 很小，而 $I_C$ 可以大很多。于是得到近似关系：
$$I_C \approx \beta I_B$$

其中 $\beta$ 是电流放大倍数，常见值可能是几十到几百。更底层一点看，$I_C$ 主要由 $V_{BE}$ **指数控制**：$$I_C \approx I_S e^{V_{BE}/V_T}$$
所以三极管既可以被说成“电流控制器件”，因为工程上常用 $I_B$ 控制 $I_C$；也可以从物理上理解为“BE 结电压控制载流子注入”。这两个说法关注层次不同，并不冲突。

### 3.2.3 总结

结合三个工作状态：

当 $V_{BE}$ 不够，BE 结没有正向导通，发射区不向基区大量注入电子，三极管截止。

当 $V_{BE}$ 正向导通，同时 $V_{CB}>0$，BE 结负责注入电子，CB 结负责收集电子，三极管处于正向有源区，可以放大信号。

当 $V_{BE}$ 正向导通，但集电极电压不够高，导致 CB 结也变成正向偏置，集电极不再能有效“吸走”电子，三极管进入饱和区。这时它更像一个已经打开的开关，继续增加基极电流也很难明显增加集电极电流。

## 3.3 类型

三极管主要分为 NPN 型和 PNP 型两类。

NPN 型由两侧 N 型半导体和中间 P 型半导体组成。它通常在基极电位高于发射极约 0.6V 至 0.7V 时导通，主电流从集电极流向发射极。实际使用中，NPN 三极管常用于低边开关，也就是负载接在电源和集电极之间，发射极接地，通过给基极输入高电平来控制负载导通。

PNP 型由两侧 P 型半导体和中间 N 型半导体组成。它的控制逻辑与 NPN 相反，通常在基极电位低于发射极约 0.6V 至 0.7V 时导通，主电流从发射极流向集电极。实际使用中，PNP 三极管常用于高边开关，也就是发射极接电源正极，负载接在集电极下方，通过把基极拉低来控制负载导通。

简单来说，NPN 更适合用“高电平导通”的方式控制接地路径，PNP 更适合用“低电平导通”的方式控制电源正极路径。两者都属于电流控制型器件，控制端都需要有基极电流流过。

# 4 增强型 MOSFET

MOSFET 是金属-氧化物-半导体场效应管（Metal-Oxide-Semiconductor Field-Effect Transistor）。它和三极管一样可以用作开关和放大器，但控制方式不同。三极管属于电流控制型器件，MOSFET 属于电压控制型器件（voltage-controlled device），主要通过栅极电压产生电场，改变漏极和源极之间的导通状态。

增强型 MOSFET（enhancement-mode MOSFET）的特点是：**初始状态下漏极和源极之间没有导电通道，器件默认关断；只有当栅极和源极之间施加足够电压时，才会在半导体表面形成导电通道，使漏极和源极导通。**

MOSFET 有三个主要引脚：栅极 G（gate）、漏极 D（drain）、源极 S（source）。部分 MOSFET 还有衬底 B（body / substrate），但在常见分立器件中，衬底通常已经和源极在内部连接，因此外部一般只引出 G、D、S 三个脚。

![[Pasted image 20260628011953.png]]

## 4.1 结构

以增强型 NMOS 为例，它通常在 P 型衬底上制作两个 N 型区域，分别作为漏极和源极。漏极和源极之间原本被 P 型半导体隔开，因此在没有栅极电压时，D 和 S 之间不能直接导通。

在漏极和源极之间的上方，有一层很薄的二氧化硅绝缘层（oxide layer）。绝缘层上方是金属栅极。由于栅极和半导体之间隔着绝缘层，所以直流状态下栅极几乎没有电流流入。栅极更像电容的一端，通过电场影响下方半导体中的载流子分布。

因此，MOSFET 的控制端不是通过“注入电流”来控制主电流，而是通过“施加电压”来改变半导体内部是否形成导电通道（channel）。

## 4.2 原理

关键： $V_{GS}$，也就是栅极相对于源极的电压（gate-source voltage）：
$$V_{GS}=V_G-V_S$$
对增强型 NMOS 来说，当栅极电压高于源极电压，并且 $V_{GS}$ 达到一定值时，栅极产生的电场会吸引电子聚集到二氧化硅下方的 P 型半导体表面。随着电子数量增加，漏极和源极之间会形成一条 N 型导电通道。

当这条导电通道形成后，D 和 S 被连接起来，电流可以从漏极流向源极。此时 MOSFET 进入导通状态（on state）。

当栅极电压降低，$V_{GS}$ 不足时，原来聚集在表面的电子减少，导电通道消失，D 和 S 重新断开。此时 MOSFET 回到关断状态（off state）。

```text
V_GS 增大
→ 栅极电场增强
→ 半导体表面聚集载流子
→ 漏极和源极之间形成导电通道
→ D 和 S 导通
```

## 4.3 种类

增强型 MOSFET 常见的两类是 NMOS 和 PMOS。

NMOS 的导通条件是 $V_{GS}$ 为正，并且足够大。也就是说，栅极电压高于源极电压时，NMOS 才可能导通。实际电路中，NMOS 常用于低边开关（low-side switch）。源极接地，漏极接负载，负载另一端接电源正极。此时 GPIO 输出高电平，$V_{GS}$ 变大，NMOS 导通，负载通电；GPIO 输出低电平，$V_{GS}$ 接近 0，NMOS 关断，负载断电。

PMOS 的导通条件与 NMOS 相反。PMOS 需要 $V_{GS}$ 为负，并且足够负。也就是说，栅极电压低于源极电压时，PMOS 才可能导通。实际电路中，PMOS 常用于高边开关（high-side switch）。源极接电源正极，漏极接负载，负载另一端接地。此时栅极被拉低，PMOS 导通，负载通电；栅极被拉到接近源极电压，PMOS 关断，负载断电。

简单来说，NMOS 常用“高电平导通”控制接地路径，PMOS 常用“低电平导通”控制电源正极路径。

## 4.4 开关特性

MOSFET 的栅极与内部半导体之间隔着绝缘层，因此稳定状态下几乎不消耗控制电流。这使它非常适合用于低功耗电路和大规模集成电路。

MOSFET 的栅极容易积累静电。若栅极悬空（floating），电压状态可能不稳定，导致 MOSFET 误导通或误关断。因此实际使用时，栅极通常需要接一个上拉电阻（pull-up resistor）或下拉电阻（pull-down resistor），使它在无输入信号时保持确定状态。

例如 NMOS 低边开关中，常在 G 和 GND 之间接一个下拉电阻，使控制信号断开时 NMOS 保持关断。PMOS 高边开关中，常在 G 和电源正极之间接一个上拉电阻，使控制信号断开时 PMOS 保持关断。

## 4.5 寄生二极管

MOSFET 内部天然存在一个寄生二极管，也叫体二极管（body diode）。这个二极管来自 MOSFET 内部的 PN 结结构。

寄生二极管会影响 MOSFET 的源极和漏极连接方向。MOSFET 导通后，沟道本身可以近似双向导电；但在 MOSFET 关断时，寄生二极管仍然可能允许某个方向的电流通过。

对于常见 NMOS，寄生二极管方向通常是从 S 指向 D。低边开关中，S 接地，D 接负载，这个二极管在正常供电方向下处于反向截止，不影响开关控制。

对于常见 PMOS，寄生二极管方向通常是从 D 指向 S。高边开关中，S 接电源正极，D 接负载，这个二极管在正常关断时可以阻止电源直接通过二极管流向负载。

## 4.6 与三极管的区别

三极管通过基极电流控制集电极和发射极之间的主电流，属于电流控制型器件（current-controlled device）。MOSFET 通过栅极电压产生电场，控制漏极和源极之间是否形成导电通道，属于电压控制型器件。

三极管导通时需要持续提供基极电流，控制端本身会消耗电流。MOSFET 稳定导通或关断时，栅极几乎不消耗直流电流，主要只在开关瞬间发生栅极充放电。
